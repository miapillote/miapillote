## Current Projects

**[Diagram IV](https://github.com/miapillote/Diagram-IV)**  
This project replicates the appearance of dense, stitched embroidery using 3D-printed half-cylinder beads precisely aligned along handwriting-based curves. By combining Python-based image processing with parametric modeling in OpenSCAD, it explores the intersection of digital fabrication and traditional textile aesthetics.

**[AutoJIRA](https://github.com/miapillote/AutoJIRA)**  
A custom-built IT ticket automation tool that integrates Google Apps Script, SQL, and Google Calendar to streamline internal support workflows. Reduces multi-step processes to a single-click submission.
